# servart-images

Images et publications Instagram programmées de Servart (https://servart.fr).

- `programme/` : publications confirmées, en attente de leur heure.
- `publie/` : publications en ligne (date et lien).
- `erreurs/` : publications non faites, à voir par l'équipe.
- Un dossier par publication : ses images en JPEG.

Tout est déposé par le Pilote Servart ; GitHub Actions publie à l'heure
prévue par l'API officielle d'Instagram (`publier.py`).
